# 🎮 Tic Tac Toe GES (Neon Glow Edition)

Welcome to **Tic Tac Toe GES**, a modern, neon-infused twist on the classic game! Built with React and Vite, this isn't your average 3x3 board. Challenge yourself on a massive **9x9 grid** where the goal is to get **5 in a row (Gomoku style)** to claim victory!

![Live Demo](https://img.shields.io/badge/Live_Demo-Play_Now-00e5ff?style=for-the-badge)
👉 **[Play the Game Here!](https://bogs-19.github.io/tic-tac-toe-ges/)**

---

## ✨ Features

* **Expanded 9x9 Grid:** A larger board requires deeper strategy. Get 5 in a row (horizontal, vertical, or diagonal) to win.
* **Neon Cyberpunk Aesthetic:** Custom-built glowing CSS effects, hovering particles, and neon strike lines.
* **Responsive Design:** Perfectly optimized for both Desktop and Mobile screens without any layout overlapping.
* **Time Travel (Timeline):** Made a mistake? Use the interactive timeline feature to jump back to any previous move in the game.
* **Holographic Victory Modal:** Celebrate your win with a procedural SVG 3D Brain Hologram animation that slides smoothly into view.

## 🛠️ Tech Stack

* **Framework:** [React 18](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** Pure CSS (CSS Variables, Flexbox, CSS Grid, Keyframe Animations)
* **Deployment:** GitHub Pages
